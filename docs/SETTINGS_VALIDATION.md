# 设置区域调整与验证

验证日期：2026-10-08（Asia/Shanghai）。本记录对应设置优化的独立提交检出，不包含工作区中其他尚未提交的构建与边界测试改动。

设置一级目录调整为主题、自动备份、数据管理、快捷键、关于。设置页不再提供颜色方案、通知、AI、插件、云同步、语言、动画、README 编辑器主题、教程和任务字段模式等选项。关于仅显示软件名称、版本号、仓库地址与问题反馈链接，字体及其他许可证文件继续随应用提供。

## 行为

- 主题提供跟随系统、浅色、深色，选择后保存。切换主题重建设置界面时保留尚未保存的快捷键草稿。
- 自动备份默认关闭，默认间隔 5 分钟，可选择 1m、5m、10m、15m、30m、1h、2h。关闭后禁用时间选项并停止定时任务；已生成的历史文件保留。
- 应用运行期间，将各项目完整快照保存到安装目录的 `backup/<项目名称--稳定标识>/`。项目同名时区分目录，重命名后沿用已有目录；文件名包含 UTC 时间戳，每次新增 `.pureproject` 文件。首次开启前检查目录可写性，失败时保留此前设置并显示错误。
- 数据管理提供导出备份与选择文件恢复，复用现有完整数据包、Excel、FreeMind 及 JSON 数据交换能力。导入先展示项目数量和同 ID 替换范围，再按确认结果提交。
- 快捷键支持按键录制、冲突校验、保存生效与恢复默认草稿。文本框保留原有编辑组合；下拉列表与内层弹窗优先处理自身按键。
