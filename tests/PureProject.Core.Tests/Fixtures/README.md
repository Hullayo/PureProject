# 固定演示样本

这里保存六份仓库自带的合成演示项目，分别来自原始 `static/` 与既有 `v1.2/static/`。项目为“智能小车项目”“Web Dashboard 重构”“移动端 App UI 设计”，均为已有示例，不含此次压力测试生成的大数据或用户工作库。

文件保持原始字节，未重新格式化。`manifest.json` 提供每个文件的相对来源、字节数、SHA-256 和来源仓库许可（MIT），同目录 `LICENSE` 保留其正文。`static/` 与 `v1.2/static/` 两组字节不同，用于覆盖已有格式的独立导入和往返。

测试项目将整个目录复制到构建及发布输出，所以 GitHub checkout 不需要另行取得旧版工作目录。样本仅供测试读取；测试不能原地保存覆盖这些文件。
